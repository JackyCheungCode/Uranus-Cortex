# Uranus Design System runtime scaffold
Future home of locally owned design foundations and controls; it does not yet replace the bootstrap UI.
- `tokens/`: CSS custom properties and semantic tokens.
- `components/`: reusable local controls.
- `patterns/`: reusable page/interaction patterns.
- `themes/`: theme definitions.
Implement controls one at a time with documented APIs, tests, accessibility behavior, and examples. Do not import Carbon into new controls.
