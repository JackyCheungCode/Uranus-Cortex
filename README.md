# Uranus Cortex

Uranus Cortex is being bootstrapped with React, TypeScript, Vite, and IBM Carbon Design System.

## Development
Prerequisites: Node.js 20+ and npm.

```sh
npm install
npm run dev
```

Quality commands: `npm run typecheck`, `npm run lint`, `npm run carbon:check`, `npm run test`, `npm run build`, and `npm audit`.

Read [AGENTS.md](./AGENTS.md), [Carbon standards](./docs/design/carbon-standards.md), and [architecture](./docs/architecture.md) before changing UI or architecture.

This is a technical foundation, not a completed product. Product workflows, persistence, authentication, and production deployment remain unspecified.
